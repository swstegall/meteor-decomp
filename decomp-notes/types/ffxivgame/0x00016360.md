# 0x01328d88 — global "temporal" bump-allocator window

Discovered while matching `FUN_00416360` (`0x00016360`, a 28-byte
`__cdecl` setter) and cross-referenced via Ghidra pseudo-C for
`FUN_00416380` (reset) and `FUN_00c1e410`
(`VfxVertexInfo::VertexDeclarationData::CreateData`, consumer).

```c
struct TemporalBuffer {           // file-scope globals, .data
    void*         base;           // [0x01328d88]  16-byte-aligned write head
    unsigned int  remaining_size; // [0x01328d8c]  bytes left in the window
};
extern TemporalBuffer g_temporal; // shared bump allocator
```

## Operations

| RVA          | Symbol         | Role                                                            |
|--------------|----------------|-----------------------------------------------------------------|
| `0x00416360` | `FUN_00416360` | `setup(buffer, size)` → align `buffer` up to 16, store aligned base in `[0x01328d88]` and residual size (`size - (aligned - buffer)`) in `[0x01328d8c]`. |
| `0x00416380` | `FUN_00416380` | `reset()` → zero both fields.                                   |
| `0x00c1e410` | `FUN_00c1e410` | Consumer (vertex-declaration writer): checks `remaining_size >> 3 <= n` for overflow, then writes through `base`. On overflow it prints "give me more temporal buffer." via `FUN_00415c90`. |

## Notes

- The allocator hands out 8-byte slots in `FUN_00c1e410`
  (`remaining_size >> 3` ≈ slot count), but the alignment is 16, so
  the *consumer* is what defines slot granularity — the buffer just
  guarantees a 16-byte-aligned start address.
- `base` is treated as a write head, not bumped per allocation — the
  consumer walks it forward in a local copy (`puVar9 = DAT_01328d88;
  puVar9 += 2;`). This is a window/staging buffer, not a true bump
  allocator with per-allocation cursor advance.
- Both globals reset to zero (not a sentinel) on `FUN_00416380`. The
  consumer's overflow check (`remaining_size >> 3 <= n`) implies a
  zero `remaining_size` is treated as "exhausted" rather than
  "uninitialised" — callers must call `setup()` before the first use.
